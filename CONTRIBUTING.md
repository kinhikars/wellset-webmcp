# Contributing

WellSet is currently optimized for a narrow competition demonstration. Small, test-backed fixes are welcome.

1. Create a focused branch.
2. Preserve the constraints in `AGENTS.md`.
3. Run `npm run verify`.
4. Explain the user-visible or reliability impact in the pull request.

Please open an issue before proposing new features or dependencies. The deterministic layout engine is intentionally simple and is not represented as laboratory-grade optimization software.
