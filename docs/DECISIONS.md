# Decision log

## 2026-09-02 — Product locked

Selected a mixed-initiative 96-well plate layout canvas after competitive and technical red-team review. The differentiator is the shared human-agent constraint interaction, not a novel optimization algorithm.

## 2026-09-02 — Static three-tool surface

Registered inspect, generate, and reflow once at page load. Dynamic tool discovery is not a hero-flow dependency because client rediscovery can be asynchronous.

## 2026-09-02 — Validation is internal

Every mutation validates automatically. Removing a separate evaluation tool reduces orchestration failure and makes state receipts authoritative.

## 2026-09-02 — Framework-free vertical slice

Used browser-native ES modules and Node's built-in test runner. This removes framework lifecycle and dependency risks while keeping the protocol integration easy to inspect.

## 2026-09-02 — Comprehension before domain detail

The permanent legend explains that each well is an experiment, position can bias results, and locked wells cannot move. The hero interaction creates countable red violations before the agent resolves them.
